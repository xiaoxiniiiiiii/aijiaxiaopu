# LUMEHAUS / 家居生活商城

全新原创视觉的 React + Vite 家居生活商城演示。

## 本地运行

```bash
npm i
npm run dev
```

构建检查：`npm run build`

## 页面

- 商城首页：`/#home`
- 全部商品：`/#shop`
- 前端后台演示：`/#admin`

后台演示账号：`admin@lumehaus.demo`  
后台演示密码：`Lumehaus2026!`

支付、订单和后台目前是前端演示流程，接入真实 PayPal / Visa 商户账户与服务端认证后才能用于生产。
